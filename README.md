# 桌宠源代码

包含当前12套桌宠的应用源码：10个单人桌宠、25时桌宠团和Leoneed桌宠团。源码从当前已修复版本的 resources/app 整理，包括休眠、窗口恢复、发言上下文及2026-10-31截图循环修复；保留每个应用内部的文件名和相对目录。

## 目录与运行

每个项目的入口位于 `角色桌宠/resources/app/package.json`，团队版入口在 `team/main.js`。具体功能和运行方法见各项目原有 README.md。

这是源码包。Electron运行程序、FFmpeg等可执行工具、node_modules、Live2D模型、贴图、图标、字体、音频和ONNX模型不包含在本包内。它们没有从已有完整桌宠压缩包或安装目录删除。

`项目与资源清单.json` 按项目记录了需要另行准备的原相对路径。要在本地运行，可以复制一份已有完整桌宠，将本包对应的 resources/app 源码覆盖到那份副本的同一位置，保留副本原有模型、素材、运行程序和依赖；或按清单补齐开发目录，再按各项目原 README 启动。直接将纯源码目录启动时，缺少模型或运行依赖会报错。

## 发布范围

本包保留原有源码、注释、第三方库标记和 package.json 的许可字段，没有另外指定许可证或添加作者署名。源码中已有的许可字段不代表游戏模型、角色音频、图片及第三方组件都采用同一许可。发布仓库时请分别列明代码与外部资源的来源和适用许可。

## 个人数据

本包未读取AppData，不含实际API密钥、个人设置、聊天记录、发言日志、录音和缓存。测试中的示例密钥为本地测试占位值。不要将运行后产生的用户数据提交到仓库；本包附有 .gitignore。

## 核对

`源码校验清单.json` 记录每个源码文件的SHA-256；导出后已与当前应用源码逐文件核对。没有为整理源码修改现有桌宠或重新运行Live2D。
